# Beauty Mirror 2.0.0

- Rebuilt the UI around a camera-first exhibition workflow.
- Added face-zone graphics and region-based editing pages.
- Added one-tap Fresh eyes, Even skin, Defined features and Stage ready corrections.
- Added spot softening, shine control, skin glow, under-eye puffiness softening, eye sparkle and brow definition.
- Exposed complete under-eye controls: correction, smoothing, maximum lift and chroma neutralization.
- Added a permanent 30 FPS protection system using average and p95 frame time, slow-frame ratio, camera FPS and analysis throughput.
- Added a 480p automatic Performance fallback that sheds optional geometry, detail restoration and feature styling before core corrections.
- Added mask caching between MediaPipe tracking updates, reduced mask budgets and optional-stage shedding, including a 480p emergency render profile.
- Requested a 30–60 FPS CameraX range where supported.
- Added `make fps`, `make perf`, `make exhibit` and `make reinstall`.
